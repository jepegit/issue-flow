# How-to guides

Short, task-oriented paths. Each page is goal → steps → related links — not a
full command reference. For every slash command in detail, see
[The workflow](../issue-workflow.md).

| Guide | When to use it |
| --- | --- |
| [Work one issue end-to-end](work-one-issue.md) | Normal pick → plan → build → close → cleanup loop |
| [Fast-track a small issue](yolo.md) | Low-risk change; one confirm then hands-off |
| [Park and resume](park-and-resume.md) | Stop mid-issue without losing state |
| [After a squash merge](after-squash-merge.md) | PR landed; tidy local (and optional remote) branches |
| [Refresh dirty open PRs](pr-sync.md) | Sibling PRs went dirty after another merge |
| [Choose a mode](choose-a-mode.md) | `novice` / `simple` / `standard` surface |
| [Create and run epics](epics.md) | Change too big for one issue |
| [Use auto mode](auto-mode.md) | Unattended epic stage + adversarial review |
