# Issue #382: bleeding edge

Source: https://github.com/jepegit/issue-flow/issues/382

## Original issue text

Would be nice to have a possibility to include a issue-flow update command with the newest issue-flow version as a part of iflow cleanup. I guess it then we need an agent function that runs uv tool install issue-flow@latest and then runs issue-flow update. This should be a knob (for example called on_bleeding_edge)
