# Issue #182: More config settings

Source: https://github.com/jepegit/issue-flow/issues/182

## Original issue text

Since we are using templates and have a configuration system in place, we should utilize it more. Create knobs, so-to-speak, that tweaks the skills from the CLI (typically `>> issue-flow update`). One example could be if we should remind user to run `/iflow-cleanup` after each `/iflow-close`. There could be many of those. Lets do a review and find at least 5. 

Message to agents:

Propose configurable knobs, their name, their default and behaviour. Ask for OK or revise or skip.
