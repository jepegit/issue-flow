# Issue #118: slash is annoying

Source: https://github.com/jepegit/issue-flow/issues/118

## Original issue text

It is annoying to always have to write slash commands. Is there a way where we can just write "iflow-plan" etc., instead of "/iflow-plan"? I guess we should still allow "/iflow-plan" etc., with the slash for those who like the "/" (and it probably gives better control).

But I hate slash. Maybe it is because I am Norwegian with a Norwegian keyboard. We don't have a forward slash as a separate key.
