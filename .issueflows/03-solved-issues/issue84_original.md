# Issue #84: archive issueflow

Source: https://github.com/jepegit/issue-flow/issues/84

## Original issue text

During development, many of the issues we have worked on are not that relevant to know about anymore. Though, some still might be. I think we should add some kind of archiving mechanism. The skill could be called "iflow-archive". It then goes through the files in (at least) solved-issues and combines it (summarizes) into a single markdown file. The file might be called [date]_archived_issues.md or something like that. Maybe we also find out a smart way to ask the user what issues to archive (or not archive) also?

One thing we should utilize is that we have a git history. So, if the archive file contains some kind of reference to last point before we did the archiving, I guess we will always have the opportunity to dig out the old md-files later on?
