# Issue #12: Create linked (sub) issues for over-ambitious issues

Source: https://github.com/jepegit/issue-flow/issues/12

## Original issue text

For the `/issue-start` command, it would be very helpful if the agent(s) could propose sub-issues if the issue is deemed too large.

We probably should add a skill on how to create new issues and how to make them be sub-issues on github

Also the /issue-start` command should be extended so that it includes this property.
