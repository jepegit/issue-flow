# Issue #246: set up project for novice and new users

Source: https://github.com/jepegit/issue-flow/issues/246

## Original issue text

User story:

User opens cursor or vscode with copilote or similar. User has been told to install issue-flow (and got help with it from our docs, first installing uv, then installing issue-flow (uv tool install issue-flow)). Then the user wants to either 1) start a new python project, or 2) work on an already existing project. If starting with new project, the user needs guidance on setting this up. For both; first the user runs issue-flow init on the command line. Then the user writes /iflow-init in the agents chat window. The agent guides the user through the setup process (if new; it needs uv init, make sure gh is installed, etc, etc).  Also, the issue-flow settings need to be set so that it is easy for users who have not used much agentic coding. 

Can we implement a solution that works for these scenarios?
