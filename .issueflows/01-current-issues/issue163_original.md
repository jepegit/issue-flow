# Issue #163: How to handle branches on GitHub

Source: https://github.com/jepegit/issue-flow/issues/163

## Original issue text

I often experience having many branches on some of my repos on GitHub, and I never remember how to find out / filter out what is useful and what can be deleted. Can issueflow help with this? For example extending iflow-cleanup with

- Checking for branches that can be deleted
- Finding branches that have new code (and summarise what code)
- Create an issue with the findings

The skill could be invoked by adding "include GitHub" and similar phrases/words after "iflow cleanup"
